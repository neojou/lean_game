# add_zero

## 概述

`add_zero a` 是 `a + 0 = a` 的證明。加法對 **右邊的 0** 沒有作用。

分類：定理 → **+**

## 示例

### 1. 改目標裡的 `+ 0`

```lean
rw [add_zero]
```

把目標中的 `? + 0` 改成 `?`。

### 2. 改假設

若 `he : x = d + 0`：

```lean
rw [add_zero] at he
```

`he` 變成 `x = d`。官方解答在 `e = 0` 那支用過類似的 `rw [add_zero]`（改目標）。

### 3. 和「左邊的 0」不同

`0 + a = a` 是另一條定理（常叫 `zero_add`）。本關背包是 `add_zero`，只處理右邊。`rfl` 也不能幫你把 `a + 0` 變成 `a`。

## 細節

精確型別：`(a : ℕ) : a + 0 = a`。

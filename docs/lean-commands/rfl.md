# rfl

## 概述

`rfl` 是 reflexivity（反身性）的縮寫。當目標是 `A = A`，而且**兩邊作為項看起來一模一樣**時，用它收掉等式。

它不管「數學上相不相等」，只看「寫出來的式子是否相同」。

## 示例

### 1. 兩邊已經長得一樣

```text
⊢ x + succ d = x + succ d
```

這時 `rfl` 會成功。

### 2. 先 `rw` 再 `rfl`

本關官方解答在改寫之後才 `rfl`：

```lean
rw [succ_eq_add_one, add_assoc]
rfl
```

`rw` 把兩邊變成同一個項，`rfl` 負責蓋章。

### 3. 什麼時候 `rfl` 沒用

```text
⊢ a + 0 = a
```

雖然對每個自然數都成立，但左邊是 `a + 0`、右邊是 `a`，**項不相同**。要先 `rw [add_zero]`，不能只靠 `rfl`。

同樣，`0 + a = a` 需要 `zero_add` 之類的定理（本關背包沒有的話就不要指望 `rfl`）。

## 細節

- `rfl` 不吃參數。
- 本遊戲的 `rfl` 比 Lean 核心弱：不會靠展開定義去證 `a + 0 = a`（加法在本遊戲是 opaque 公理）。
- 目標若不是等式（也不是 `↔`），`rfl` 會失敗。

## 本遊戲的實作

刻意不讓 `rfl` 偷偷用定義把 `add_zero` 證掉，這樣你才需要真的去用 `add_zero`、`add_succ` 這些定理。

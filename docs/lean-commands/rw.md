# rw

## 概述

`rw` 是 rewrite（改寫）。若你有等式 `h : X = Y`（或定理如 `add_zero`），`rw [h]` 會把**目標裡的 `X` 換成 `Y`**。

本遊戲的 `rw` 行為像 Lean 的 `rewrite`：**不會**在最後自動 `rfl`。改完若兩邊已經相同，請自己再下 `rfl`。

## 示例

### 1. 改目標

```lean
rw [add_zero]
```

若目標含有 `? + 0`，會變成拿掉 `+ 0` 的版本。

一次改多個：

```lean
rw [succ_eq_add_one, add_assoc]
```

由左到右依序改寫。

### 2. 反向改寫

若 `h : succ n = n + 1`，而你想把 `n + 1` 變成 `succ n`：

```lean
rw [← succ_eq_add_one]
```

`←`（或 `<-`）表示用等式的另一個方向。

### 3. 改假設（`at`）

官方解答有：

```lean
rw [add_succ] at he
```

這是改 **hypothesis** `he`，不是改目標。當等式藏在假設裡時用這個。

也可以：

```lean
rw [h1]
```

若 `h1` 本身是等式，預設改的是目標。

### 4. 改不到會失敗

若目標裡根本沒有定理左邊的那個模式，`rw` 會報「找不到可改寫的模式」。檢查你是不是該 `rw […] at 某個假設`，或該先 `cases` 拆出等式。

## 細節

- 語法：`rw [t1, t2, …]`，可加 `at h`。
- 本遊戲 `rw` 與網站 NNG 對齊：不做收尾 `rfl`。若你習慣 Mathlib 的 `rw` 會自動 `rfl`，在這裡請多打一行 `rfl`。

## 本遊戲的實作

`rw` 被做成 `rewrite` 的別名，避免自動 `rfl` 把你準備好的下一行 `rfl` 用到別的 goal 上。

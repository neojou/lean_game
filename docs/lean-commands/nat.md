# ℕ

## 概述

`ℕ` 是本遊戲的自然數，真正的型別名是 `MyNat`。它不是 Lean 標準庫的 `Nat`，而是用 Peano 方式自建的：

- `0`
- `succ n`（`n` 的後繼）

## 示例

### 1. 假設裡的 `x y : ℕ`

本關一開始就有 `x y : ℕ`，表示兩個自然數。

### 2. 對 `ℕ` 做 `cases` / `induction`

每個自然數不是 `0` 就是某個 `succ b`：

```lean
cases a with b
induction y with d hd
```

### 3. 數字字面量

`1`、`0` 可以寫在 `use 1` 裡；`1` 定義上是 `succ 0`。

## 細節

本遊戲把 `ℕ` 當成 `MyNat` 的符號。加法 `+`、序 `≤` 都建在這個型別上，而不是電腦裡的 64 位整數。
